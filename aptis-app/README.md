# Aptis - Luyện Thi Aptis ESOL

Nền tảng luyện thi Aptis ESOL toàn diện đầy đủ 4 kỹ năng (Reading, Listening, Writing, Speaking) tích hợp hệ thống AI Chấm điểm & Đánh giá theo chuẩn CEFR và bộ khung mẫu đạt Band C.

## 🚀 Các Tính Năng Nổi Bật

- **Reading (4 Parts)**: Luyện tập hoàn thành câu, liên kết đoạn văn, nối ý kiến người nói, ghép tiêu đề đoạn.
- **Listening (4 Parts)**: Trình phát audio giọng đọc bản ngữ, bài tập trắc nghiệm, nhận diện người nói và bài độc thoại mở rộng.
- **Writing (4 Parts)**: Luyện viết từ câu ngắn Form Filling, Social Club Chat đến Email Formal & Informal với AI Chấm 4 tiêu chí và gợi ý bài mẫu Band C.
- **Speaking (4 Parts)**: Mô phỏng phòng thi Speaking chuẩn thời gian thực, ghi âm/nhập bản ghi nói, chấm điểm và góp ý chi tiết.
- **AI Chấm Điểm & Nâng Cấp Band C**: Phân tích tiêu chuẩn Task Fulfillment, Grammar, Vocabulary, Cohesion và cung cấp bản dịch song ngữ.
- **Chế độ Study Mode & Reset**: Luyện tập linh hoạt, xem trước đáp án, giải thích chi tiết và reset làm lại bất kỳ lúc nào.

## 🛠️ Hướng Dẫn Cài Đặt & Chạy Dự Án

```bash
# Cài đặt dependencies
npm install

# Chạy môi trường phát triển (Development)
npm run dev

# Đóng gói ứng dụng (Production Build)
npm run build
```
